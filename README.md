# RELOPOLI

Repository dokumentasi resmi rancangan game Relopoli.

## Source of Truth

Mulai dari [`docs/MASTER_SOURCE_OF_TRUTH.md`](docs/MASTER_SOURCE_OF_TRUTH.md). Jika ada konflik, ikuti latest explicit locked decision sesuai hierarki sumber yang dijelaskan di dokumen master.

## Struktur

- `docs/MASTER_SOURCE_OF_TRUTH.md`: aturan utama yang dikonsolidasikan.
- `docs/progress/`: master flow dan dokumentasi progres.
- `docs/systems/`: spesifikasi mekanik dan sistem.
- `docs/audit/`: edge case, exploit audit, dan backlog review.
- `docs/ui/`: spesifikasi UI.
- `docs/visual/`: arah visual.
- `design/`: referensi katalog properti.

## Status

Dokumentasi desain. Ini bukan bukti bahwa seluruh sistem sudah diimplementasikan atau diuji di Roblox.
